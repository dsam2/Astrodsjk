# Document 04 — UI/UX Design Brief

## Visual Aesthetics & Design System

| Attribute | Specification |
| :--- | :--- |
| **Aesthetic Direction** | Modern Celestial Luxury & Classical Vedic Editorial |
| **Primary Theme** | Dark Cosmic (Deep Slate `#0F172A`, Nebula Purple `#7C4DFF`, Warm Gold `#F6C85F`) |
| **Light Theme** | Warm Alabaster (`#FAF8F5`), Copper/Terracotta (`#9A5B2C`), Charcoal (`#1C1917`) |
| **Typography** | Display: `Cormorant Garamond` (Serif)<br>Body: `Inter` (Sans-serif)<br>Numbers/Coordinates: `Space Grotesk` (Monospace) |
| **Card Styling** | Glassmorphism blur (`backdrop-filter: blur(12px)`), 1px subtle borders, warm elevation |
| **Micro-Interactions** | Smooth scroll reveals, theme toggle transitions, dynamic SVG chart rendering |
| **Responsive Breakpoints** | Desktop (1440px), Laptop (1024px), Tablet (768px), Mobile (375px) |

---

## Interactive Design Guidelines

1. **Chart Interactivity**: Clean vector SVG paths for North-Indian and South-Indian chart styles with responsive scaling.
2. **Form Ergonomics**: Floating label inputs, integrated city search autocomplete, and instant feedback validation.
3. **Accessibility**: High contrast text elements (WCAG AA compliant), clear focus states, and aria labels on interactive controls.
